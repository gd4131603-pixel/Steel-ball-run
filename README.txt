# Site: Bora ver Steel Ball Run?

## Arquivos
- `index.html`: página com os botões Sim e Não.
- `videos/sim.mp4`: vídeo que você enviou, ligado ao botão Sim.
- `videos/nao.mp4`: coloque aqui o segundo vídeo quando você enviar.

## Para adicionar o segundo vídeo
1. Coloque o segundo vídeo dentro da pasta `videos`.
2. Renomeie o arquivo exatamente para `nao.mp4`.
3. Envie/substitua os arquivos no repositório do GitHub.

Os vídeos ficam em loop. Se o navegador bloquear a reprodução automática, basta tocar em Play.
